{# 5 ─ Project-based learning #}

Project-based learning

We teach through a real project, in this order.

  1. Learn the concepts

    Start with the ideas the project depends on.

  2. Understand the problem

    Be clear about what the project must solve and why.

  3. Plan the implementation

    Decide the approach, tools and structure before building.

  4. Develop the project

    Build it hands-on, with guidance from a mentor.

  5. Test and improve

    Check the results, find what falls short and refine it.

  6. Understand the outcome

    Be able to explain how the finished project works.

{{ icon('file') }}Mentora Labs does not promise grades, job placements or any guaranteed result. The aim is that you understand and can explain what you have built.
